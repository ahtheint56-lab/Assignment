# Student Performance Analyzer 🎓

This program is a Python application that collects student information and scores, and calculates performance status and summary statistics.

## ✨ Features
- Accepts information (Name, Age, Study Hours, and Python Score) for at least 5 students.
- Validates whether the entered scores are between 0 and 100.
- Automatically classifies grades based on the scores:
  - 80 to 100 - Excellent
  - 60 to 79 - Good
  - 40 to 59 - Pass
  - 0 to 39 - Fail
- Calculates and displays statistics such as total student count, average score, highest score, and lowest score.
